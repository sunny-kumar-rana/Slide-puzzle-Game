🧩 Slide Puzzle GameAn interactive, browser-based Slide Puzzle (often known as the 15-puzzle) built with a focus on smooth logic and responsive design. Challenge your spatial reasoning by rearranging tiles into their correct numerical or visual order.


✨ FeaturesDynamic Grid: A classic tile-based layout with a "hole" for sliding movements.Smooth Interactivity: Responsive click-to-move or drag-to-move mechanics.Win Detection: Real-time checking to notify the player when the puzzle is successfully solved.Shuffle Logic: An algorithm that ensures every shuffled state is mathematically solvable.Responsive Design: Playable on both desktop and mobile browsers.🛠️ Tech StackLayerTechnologyStructureHTML5 (Semantic Tags)StylingCSS3 (Flexbox/Grid & Transitions)LogicVanilla JavaScript (ES6+)


🚀 Getting StartedPrerequisitesNo special installation is required—just a modern web browser.InstallationClone the repository:Bashgit clone https://github.com/sunny-kumar-rana/Slide-puzzle-Game.git
Navigate to the project folder:Bashcd Slide-puzzle-Game
Run the game:Simply open index.html in your browser.


🎮 How to PlayThe Goal: Arrange the tiles in ascending order (usually starting from the top-left) by sliding them into the empty space.Movement: Click on any tile adjacent to the empty slot to move it into that slot.Winning: Once all tiles are in the correct sequence, the "Win" state is triggered!
